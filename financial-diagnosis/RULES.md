# RULES.md — financial-diagnosis 会计口径与判断规则

> 分工文档要求 A/B/C 各交一份 `RULES.md`，写"金融规则与判断标准"。
> 本文件是 B 的**会计口径规则**：哪些数字能信、怎么配、什么时候"不判"。
> 指标公式与阈值表见 `ratio_formulas.md`，风险规则见 `../risk-radar/risk_rules.json`。

---

## 一、数据来源的可信度分级

不是年报上写的每个数字都同等可信。B 在计算前先做一次可信度分级，分级结果会传导到风险等级。

| 级别 | 来源 | 处理方式 |
|---|---|---|
| L1 最高 | 经审计的合并财务报表主表（三表） | 直接使用 |
| L2 高 | 财务报表附注（应收账款账龄、借款明细、商誉） | 用于细化分析 |
| L3 中 | 管理层讨论与分析（MD&A）中的口径说明 | 只用于文字归因，**不用于计算** |
| L4 低 | 公司自行披露的"调整后""经调整"口径（如经调整净利润） | **默认不使用**；若使用必须显式标注为"公司口径" |

**规则**：本模块计算只使用 L1 与 L2 数据。C 的估值模块若使用 L4 口径（常见：经调整 EBITDA），
必须在统一对象的 `sources` 里单独标注口径差异。

## 二、单位与精度规则

| 规则 | 内容 |
|---|---|
| R-U1 | 输入可以是亿元 / 万元 / 千元 / 元，B 内部一律归一到**元**（float）再计算 |
| R-U2 | 输出金额字段单位为**元**；`evidence` 里同时保留 `display_value` + `display_unit` 供展示 |
| R-U3 | 比率一律输出小数（`0.2309` = 23.09%），**不输出百分比数字**，由展示层格式化 |
| R-U4 | 计算过程保留完整浮点精度，输出时统一保留 6 位小数 |

## 三、时期与存量口径规则

| 规则 | 内容 |
|---|---|
| R-P1 | 利润表、现金流量表 = **流量**（期间发生额）；资产负债表 = **存量**（时点余额） |
| R-P2 | 所有「流量 ÷ 存量」指标，分母用 **平均余额 =（期初 + 期末）/ 2** |
| R-P3 | 期初 = 上一期期末。要算「上期指标」，需要 t-2 的资产负债表余额 → **所以 A 必须提供三期数据** |
| R-P4 | 周转天数统一用 `days_in_year = 365`（不做 360 / 365.25 的差异化） |
| R-P5 | 合并报表口径，不使用母公司报表（母公司报表会漏掉子公司真实负债） |

## 四、口径匹配规则（最容易出错的地方）

| 规则 | 内容 | 反例 |
|---|---|---|
| R-M1 | ROE：分子**归母**净利润，分母**归母**净资产 | 用净利润 ÷ 全部权益 → 高估 |
| R-M2 | ROA：分子净利润**含**少数股东损益，分母总资产 | 用归母净利 ÷ 总资产 → 低估 |
| R-M3 | ROIC：NOPAT（全口径 EBIT）× (1−有效税率) ÷（有息负债 + **归母**净资产） | 用全部权益 → 重复计入少数股东 |
| R-M4 | 有息负债只含：短期借款 + 一年内到期非流动负债 + 长期借款 + 应付债券 | 把应付账款算进去 → 虚增杠杆 |
| R-M5 | 周转率分子用**营业收入**（不是含税收入），分母用**账面余额**（不是净值） | 用应收账款净值 → 高估周转 |
| R-M6 | 存货周转率分子用**营业成本**（不是营业收入） | 用收入 → 虚增周转率 |

## 五、缺失值与异常值规则

| 规则 | 内容 |
|---|---|
| R-D1 | **不猜数。** 输入缺失 → `value: null` + `status: "not_meaningful"` + 进 `review_queue` |
| R-D2 | 分母为 0 → 同上。不返回 `inf` / `NaN` / `0` |
| R-D3 | 上期为负导致增长率无意义（如扭亏） → 同上，不做"取绝对值"之类的花活 |
| R-D4 | 单位缺失 → 回退到 `meta.default_unit`，正常计算但进 `review_queue` 提示核对 |
| R-D5 | 页码缺失 → 不影响计算，证据链该节点 `page: null`，提示回查 A |
| R-D6 | **本期与上期的会计口径若发生变化（如新收入准则、合并范围变化），本模块无法自动识别，必须由 A 在 `meta` 里标注 `accounting_policy_change: true`，否则所有"变化类"结论都不可信** |

## 六、指标变动归因的判断标准

| 规则 | 内容 |
|---|---|
| R-A1 | **杜邦三段必须闭合。** `净利率效应 + 周转率效应 + 杠杆效应 = ROE 变动`（允许 ±0.01pp 的浮点误差）。不闭合说明口径错了。 |
| R-A2 | 归因结论必须给出**主次排序**，不能只列三个数字。句式："主要由 X 驱动，Y 部分对冲"。 |
| R-A3 | 营业利润桥的"其他效应"是残差，**绝对值超过 Δ营业利润 的 50% 时，必须提示"存在未解释部分，需人工核查"**（通常意味着有大额减值、其他收益或营业外收支）。 |
| R-A4 | 现金流桥的"其他（倒轧）"项若超过净利润的 30%，同样需要提示。 |
| R-A5 | 归因只解释"是什么驱动的"，**不解释"为什么"**——"为什么"需要读 MD&A 与附注，属于对话层的活。 |

## 七、与上下游的边界

| 边界 | 规则 |
|---|---|
| 与 A | A 负责"抽出来"，B 负责"算出来"。B **不重新抽取**任何数据，也不修正 A 的数字。发现可疑（如三表勾稽不平）→ 进 `review_queue`，不自行修改。 |
| 与 C | B 提供 `ratios`，C 提供 `wacc` 与行业基准。C 的 DCF 需要的 FCF、EBIT、净负债，B 已在 `derived` 与 `ratios` 里给全，**C 不应重复计算**。 |
| 与 D | D 只做搬运与合并，不重新计算。 |
| 与 E | E 只读不写，只做渲染。 |

### 三表勾稽自检（v1.2 已落地：B 检查，但不自动修正）

三条关系逐期检查，结果落在输出的 `checks` 节点：

| 勾稽关系 | 公式 | 检查项 id |
|---|---|---|
| 资产负债表平衡 | 总资产 = 总负债 + 归母股东权益 + 少数股东权益 | `bs_balance` |
| 利润表勾稽① | 利润总额 − 所得税费用 = 净利润 | `is_tax_bridge` |
| 利润表勾稽② | 净利润 − 归母净利润 = 少数股东损益（与附注独立披露值比对） | `is_minority_split` |
| 现金净变动 | 期末现金 − 期初现金 = 经营 + 投资 + 筹资 + 汇率影响 | `cf_reconcile` |

**处置规则**：差异 `|左 − 右|` 超过对应科目绝对值的 **1%** → 判 `imbalanced` 并写入
`review_queue`（`type = articulation_break`），提示"勾稽不平，请核对抽取结果"。

**三条实现上的坑（都是踩过的）**：

1. **利润表②会退化成恒真式**。若少数股东损益是用「净利润 − 归母净利润」倒轧的，
   代入原式得 `归母净利 + (净利润 − 归母净利) ≡ 净利润` —— 永远成立，抓不到任何错。
   所以本项**只在附注独立披露该数（字段 `minority_pnl`）时才判平衡/不平**，
   否则判 `not_evaluable`。宁可写"查不了"，也不能拿恒真式冒充"查过了"。
2. **现金口径必须同源**。现金流量表的「现金及现金等价物」才是与三项净额同源的口径；
   资产负债表的「货币资金 / 现金及存放中央银行款项」含受限资金与法定准备金，
   拿它去对三项净额必然不平（工行两者相差上万亿）。故优先取 `cf_cash_end`。
3. **容差基准不能取被扰动项本身**。差异基准取「左值、右值绝对值较大者」，
   避免净变动接近 0 时容差退化成 0、任何噪声都判不平。

回归测试见 `scripts_test_checks.py`（注入已知失衡 → 断言被抓出）。

## 八、会计判断的权威依据（为什么这些口径非如此不可）

本模块的口径选择不是拍脑袋，背后是会计准则实务长期强调的专业判断框架
（谨慎性、普通股股东视角、实质重于形式、合并报表准则），每一项都可追溯到具体准则条文。
把依据写在这里，是为了让"口径"**可复核**，而不是"信我"。完整引用见 `../references/accounting_standards_basis.md`。

### 8.1 谨慎性原则 → 不猜数（R-D1～R-D6）

《企业会计准则——基本准则》第十八条将"谨慎性"列为八项会计信息质量要求之一：
对交易或事项存在不确定性时，不应高估资产或收益、低估负债或费用。

→ 直接对应 R-D1：输入缺失、分母为 0、扭亏导致增长率无意义，一律 `null` + `not_meaningful`，
**绝不用行业均值 / 历史值 / "合理假设"填充**。在投研场景，编造的数字比缺失危险得多。

### 8.2 普通股股东视角（权益法）→ ROE / ROA / ROIC 的归母基准（R-M1、R-M3）

权益法核算下，投资方享有的被投资单位净损益与净资产份额，以"归属普通股股东"为基准；
永续债、优先股等分类为"其他权益工具"的项目，不构成普通股股东权益
（权益法下需从被投资单位净利润中扣除归属于永续债持有人的部分）。

→ 这正是 `banking.roe_common`（**归母普通股股东权益**）的设计依据：分母剔除其他权益工具后，
ROE 才与年报披露的普通股股东口径一致（工行实证 9.51% vs 披露 9.45%，差异仅来自加权时点）。
ROIC 同理只计归母净资产，避免少数股东权益被重复计入。

### 8.3 实质重于形式 → 永续债 / 优先股的分类（R-M2、R-M4）

《企业会计准则第 37 号——金融工具列报》及《金融负债与权益工具的区分及相关会计处理规定》
要求按"是否负有交付现金或其他金融资产的合同义务、是否通过交付自身权益工具结算"
判断一项工具是金融负债还是权益工具——看经济实质而非法律名称。

→ 永续债若含"无条件避免交付现金"的强制付息 / 赎回条款，应分类为金融负债（计入有息负债）；
分类为"其他权益工具"的，既不能进普通股股东权益（8.2），也不能进有息负债（R-M4）。
本模块不自动判断，交由 A 在 `meta` 标注 `other_equity_instruments` 余额及分类。

### 8.4 合并报表准则 → 归母 vs 少数股东的划分（三表勾稽②）

《企业会计准则第 33 号——合并财务报表》规定，净利润与净资产需在归母股东与
少数股东之间分摊。少数股东损益是附注**独立披露**的科目，不是"净利润 − 归母净利"的倒轧量。

→ 所以三表勾稽②（`is_minority_split`）只在 `minority_pnl` 独立披露时才判平衡 / 不平；
否则用倒轧量代入得恒等式 `归母 + (净利 − 归母) ≡ 净利`，恒真、零鉴别力，必须报 `not_evaluable`。
**宁可写"查不了"，也不能拿恒真式冒充"查过了"。**
