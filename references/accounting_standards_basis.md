## 一、支撑"不猜数"的：谨慎性原则

| 项目 | 内容 |
|---|---|
| 依据 | 《企业会计准则——基本准则》第十八条（会计信息质量要求：谨慎性） |
| 条文核心 | 企业对交易或事项进行会计确认、计量和报告时，应保持应有的谨慎，**不应高估资产或收益、低估负债或费用** |
| 落到 B 模块 | `financial-diagnosis/RULES.md` 第五节（R-D1～R-D6）：输入缺失 / 分母为 0 / 扭亏导致增长率无意义 → `null` + `not_meaningful`，绝不填充；`risk-radar` 的 F3：缺失输入一律 `not_evaluable`，不默认安全 |

## 二、支撑"归母普通股口径"的：权益法与普通股股东视角

| 项目 | 内容 |
|---|---|
| 依据 | 《企业会计准则第 2 号——长期股权投资》及应用指南（权益法核算）；合并报表准则对归属于母公司普通股股东口径的要求 |
| 条文核心 | 权益法下，投资方按**应享有被投资单位净损益的份额**确认投资收益；该份额以"归属普通股股东"为基准。永续债、优先股等分类为"其他权益工具"的项目，不构成普通股股东权益 |
| 实务要点（HE11） | 计算投资收益时，需从被投资单位净利润中扣除归属于永续债持有人的部分（非累积按本期实际宣告、累积按本金×票面利率） |
| 落到 B 模块 | `banking.roe_common`（归母普通股股东权益）：分母剔除其他权益工具后，ROE 与年报普通股股东口径一致；`roic` 只计归母净资产，避免少数股东权益重复计入（R-M1、R-M3） |

## 三、支撑"永续债 / 优先股分类"的：实质重于形式

| 项目 | 内容 |
|---|---|
| 依据 | 《企业会计准则第 37 号——金融工具列报》；《金融负债与权益工具的区分及相关会计处理规定》（财会〔2014〕13 号）；《永续债相关会计处理的规定》（财会〔2019〕2 号） |
| 条文核心 | 按"是否负有交付现金或其他金融资产的合同义务 / 是否通过交付自身权益工具结算"判断金融负债还是权益工具——**看经济实质，不看法律名称** |
| 实务判定 | 永续债若含"无条件避免交付现金"的强制付息 / 赎回条款 → 金融负债（计入有息负债）；分类为"其他权益工具"的，既不进普通股股东权益（第二节）、也不进有息负债（R-M4） |
| 落到 B 模块 | 本模块不自动判断分类，交由 A 在 `meta` 标注 `other_equity_instruments` 余额及分类；风险规则据此决定是否纳入杠杆 / 资本口径 |

## 四、支撑"归母 vs 少数股东划分"的：合并报表准则

| 项目 | 内容 |
|---|---|
| 依据 | 《企业会计准则第 33 号——合并财务报表》 |
| 条文核心 | 净利润与净资产应在归属于母公司股东与少数股东之间分摊；少数股东损益是附注**独立披露**的科目 |
| 落到 B 模块 | 三表勾稽②（`is_minority_split`）只在 `minority_pnl` 独立披露时判平衡 / 不平；用倒轧量代入会退化成恒真式 `归母 + (净利 − 归母) ≡ 净利`，故缺失时强制 `not_evaluable`（RULES.md 8.4） |

## 五、支撑"监管导向阈值"的：监管规则与红线

| 指标维度 | 监管依据 | 关键红线 | 落到 B 模块 |
|---|---|---|---|
| 资本充足率 | 《商业银行资本管理办法》（国家金融监督管理总局） | 核心一级 / 一级 / 资本充足率监管底线（分档） | `banking` 剖面 `regulatory_basis`；B04 资本充足率下滑 |
| 拨备覆盖率 | 《商业银行贷款损失准备管理办法》 | 拨备覆盖率监管底线 **120% / 150%** | 银行业专属规则，区分"越红线"（合规）与"低于同业"（竞争） |
| 流动性覆盖率 | 《商业银行流动性风险管理办法》 | LCR **≥ 100%** | 流动性维度（当前剖面未纳 LCR，列为已知局限） |
| 会计类监管 | 《监管规则适用指引——会计类》（证监会，第 1～X 号） | 收入总额法 / 净额法、权益性交易、非经常性损益认定等权威口径 | 风险归因与建议的口径基准 |

> **越红线 vs 低于同业**：行业剖面第④层 `regulatory_basis` 把二者分开——越监管红线是合规问题，
> 低于同业均值是竞争问题，风险含义完全不同，混谈会让风险等级失去意义。

## 六、支撑"确定性分级"的：表达确定性

| 严重度 | 对应确定性分级 | 表达强度 |
|---|---|---|
| `high` 重大 | 应当 | 强确定 |
| `medium` 关注 | 建议可以 | 中确定 |
| `low` 提示 | 可能 | 弱确定 |
| `passed` 未触发 | —— | 仅表示"本条已查、未达触发线"，**非**"确定安全" |

## 七、使用约定

1. **引用格式**：正文引用写《企业会计准则第 X 号》或监管文件简称 + 核心条款；不写未核实的文号。
2. **版本时效**：准则 / 监管文件会修订，使用前以官方最新有效文本为准（本文件信息截至 2026-05）。
3. **不替代原文**：本文件是"为什么这么算 / 这么判"的依据索引，不是准则正文；精确适用请查证原文。
4. **诚实标注**：凡未能用可比公司分位数统计校准的阈值，在产出中明确 `benchmarks_calibrated: false`，
   不把通用档 / 公开均值伪装成"已校准行业基准"。
