# 真实案例 · 中国工商银行（601398.SH）

> 用**真实年报公开披露数据**端到端跑通 B 的两个引擎。
> 选工行不是因为它典型——恰恰因为它**最不典型**。银行没有应收账款、没有存货、没有毛利率，
> 用制造业口径套它会全面崩盘。这是检验"行业自适应阈值"最狠的压力测试。

## 3. 结果

### 3.0 三表勾稽自检（11 项全部平衡）

在算指标之前先验证抽取数据本身是否自洽：

| 勾稽关系 | 期间 | 左值 | 右值 | 差异 |
|---|---|---|---|---|
| 总资产 = 总负债 + 归母股东权益 + 少数股东权益 | 2023 / 2024 / 2025 | 446,970.79 / 488,217.46 / 534,777.73 亿元 | 同左 | 0.00 |
| 利润总额 − 所得税费用 = 净利润 | 2023 / 2024 / 2025 | 3,651.16 / 3,669.46 / 3,707.66 亿元 | 同左 | 0.00 |
| 净利润 − 归母净利润 = 少数股东损益 | 2023 / 2024 / 2025 | 11.23 / 10.83 / 22.04 亿元 | 同左 | 0.00 |
| 期末现金 − 期初现金 = 经营 + 投资 + 筹资 + 汇率影响 | 2023→2024 / 2024→2025 | −4,653.28 / −5,213.94 亿元 | 同左 | 0.00 |

> **口径提示**：现金勾稽必须用**现金流量表**的「现金及现金等价物」，
> 不能用资产负债表的「现金及存放中央银行款项」——后者含法定存款准备金，
> 工行两者相差上万亿，直接对比必然"不平"。引擎已按此口径优先取 `cf_cash_end`。

### 3.2 风险层 —— 正确口径（银行业剖面）

```
规则 53 条 | 适用 23 | 不适用 30 | 触发 3（重大 0 / 关注 2 / 提示 1）| 通过 18 | 不可评估 2
综合风险：低（19.2）  待核验 2 项
```

| 触发项 | 级别 | 事实 |
|---|---|---|
| B04 资本充足率下滑 | 关注 | 18.76%，同比 −0.63pp；核心一级 13.57% |
| B06 净息差收窄 | 关注 | NIM 1.28%，同比 −14BP；净利差 1.15% |
| B13 分红率与资本充足率同时承压 | 提示 | 现金分红率 35.86%，同时资本充足率下降 |

**这个结论是成立的**：工行是一家资本充足（18.76% 远高于 11.25% 监管底线）、
资产质量改善（不良率 1.34%→1.31%）、拨备厚实（213.60%）的银行，
真正的压力点就是整个行业共同面对的**息差收窄**。三条风险全在点上，没有一条是噪声。

### 3.3 对照组 —— 误用制造业通用口径

```
规则 40 条 | 适用 40 | 不适用 0 | 触发 2（重大 1 / 关注 1）| 通过 16 | 不可评估 22
综合风险：较低（25.9）  待核验 64 项
```

| 触发项 | 级别 | 问题 |
|---|---|---|
| S01 资产负债率偏高 | **重大** | 91.5% vs 通用阈值 60% —— 银行常态本就在 90% 以上，**纯误报** |
| P03 ROE 低于资本成本 | 关注 | 用 WACC=9% 当资本成本，但银行的"资本"约束是资本充足率，**口径错误** |

同时：22 条规则退化成"不可评估"（因为银行根本没有应收/存货数据），
待核验队列从 2 项暴涨到 64 项。

**同样是工商银行，同一份数据，换个行业口径，结论从"息差承压的稳健大行"
变成"资产负债率 91.5% 的重大风险企业"。** 这就是行业自适应阈值必须做的原因。

## 4. 这个案例证明了什么

### 4.1 指标引擎能接住非制造业报表

银行业专属指标 23 个全部算通：NIM、净利差、信用成本、不良率、拨备覆盖率、
贷款拨备率、资本充足率三级、RWA 占比、存贷比、ROA/ROE 银行口径、RWA 收益率等。
关键校验全部踩中年报披露值。

### 4.2 行业剖面机制真的在起作用

30 条不适用规则被正确屏蔽（应收、存货、流动比率、利息保障倍数、毛利率……），
13 条银行业专属规则被自动追加。不是"少报风险"，是"**不报假风险**"。

### 4.3 三态判定不是摆设

对照组里 23 条规则因为没有应收/存货数据变成 `not_evaluable` 并进待核验队列，
而不是被当成"通过"——**算不出来 ≠ 没有风险**，这条铁律在真实数据上验证过了。

### 4.4 全流程只用公开信息

年报 PDF 来自巨潮（证监会指定披露平台），字段带页码，审计意见为外部机构出具。
没有任何内部数据、没有付费数据源、没有未经披露的估计。

## 5. 已知局限

- **行业阈值未统计校准**：银行业剖面里的阈值来自公开监管规则与公开行业均值，
  并非我们自己跑可比公司分位数得出。要真正"结合行业情况"，需要 C 提供可比公司池的分位数。
  这一点 manifest 里用 `benchmarks_calibrated: false` 明确标注了，没有伪装成已校准。

- **WACC 缺失**：两条依赖 WACC 的规则（P03、B12）进待核验。我们**没有**随手填一个
  看起来合理的数字——填了就无法分辨"判断"和"编造"。

- 银行特有的 LCR / NSFR / 流动性覆盖率等指标未纳入，需从年报"流动性风险"章节单独抽取。
