# 金融规则与判断标准

本文件说明估值模块用的**规则、默认值及其理由**，以及**什么时候该停下来**。

---

## 一、市场默认参数

两套口径分开，因为 A 股与美股的无风险利率、风险溢价差得很远。

| 参数 | A 股 | 美股 | 理由 |
|---|---|---|---|
| 无风险利率 rf | 1.8% | 4.28% | 各自基准日的 10 年期国债收益率。**运行时用实际取到的值覆盖** |
| 股权风险溢价 ERP | 5.14% | 4.28% | Damodaran 国家风险溢价表：中国为成熟市场 ERP + 中国 CRP |
| 税前债务成本 Kd | 3.5% | 5.5% | A 股用 5 年期以上 LPR；美股用投资级信用利差。**优先用「利息费用 ÷ 有息负债」** |
| 永续增长率上限 | **4.0%** | **3.0%** | 中国长期名义 GDP 5–6%，美国 4–4.5%。永续增长不该超过长期名义 GDP |
| 默认永续增长率 | 2.5% | 2.5% | 保守取值 |

> 这两条永续增长率上限取自 Damodaran 的长期 GDP 口径：
> 中国 5.0–6.0% → 可辩护上限 4.0%；美国 4.0–4.5% → 上限 3.0%。

## 二、假设的取法

**核心原则：用中位数，不用最近值。**

| 假设项 | 取法 | 为什么 |
|---|---|---|
| EBIT 利润率 | 近三年中位数 | 平滑周期噪声与一次性损益 |
| 折旧摊销率 | 近三年中位数 | 同上 |
| 资本开支率 | 近三年中位数 | 同上 |
| 营运资本率 | 近三年中位数 | 同上 |
| 所得税率 | 近三年有效税率中位数，**夹在 15%–30%** | 剔除一次性税务事项；上下限防止异常值 |
| 首年收入增速 | 一致预期优先，其次历史 CAGR | 历史 CAGR 是后视的，一致预期反映未来 |
| 同业倍数 | **中位数**，不是均值 | 中位数对极端值稳健 |

**税率为什么要夹在 15%–30%**：高新技术企业 15%，一般企业 25%。低于 15% 通常是
有大额税收优惠或一次性抵扣，不可持续；高于 30% 通常是汇算清缴口径差异。

## 三、可比公司的选法

| 标准 | 优先级 |
|---|---|
| 同一行业 | 必须 |
| 商业模式相似（如设备 vs 耗材） | 必须 |
| 增速接近（相差 ±10 个百分点内） | 强烈建议 |
| 利润率接近 | 建议 |
| 资本结构接近 | 加分项 |
| 地域敞口接近 | 加分项 |

**家数：4–6 家。** 太少不稳健，太多噪声大。

**避免**：拿多元化巨头去对标专一业务的中小公司。

**目标与同业差异明显时**，对倍数做调整并**说明理由**：

| 目标相对同业 | 倍数调整 |
|---|---|
| 增速高 500bp 以上 | +10% ~ +30% |
| 增速低 | −10% ~ −30% |
| 利润率高 300bp 以上 | +10% ~ +20% |
| 利润率低 | −10% ~ −20% |
| 杠杆低 / 资产负债表更好 | +5% ~ +10% |
| 杠杆高 / 有债务风险 | −10% ~ −20% |
| 有市场支配地位 / 护城河 | +10% ~ +20% |

**剔除异常样本**：PE > 100 或 EV/Revenue > 50 的，除非目标本身同样极端。

## 四、终值

用两种方法**取中点**，不要只用一种：

```
Gordon 永续法：TV = FCFF_n × (1+g) ÷ (WACC − g)
退出倍数法：  TV = EBITDA_n × 同业中位 EV/EBITDA
终值 = (Gordon + 退出倍数) ÷ 2
```

**为什么要取中点**：Gordon 法对 `WACC − g` 极敏感，分母小一点点结果就差很多；
退出倍数法锚定市场，但会随情绪波动。两者平均可以互相纠偏。

**偏离度检查**：两种算法偏离超过 30% 要回头核对。**偏离的常见根因是 `WACC − g` 太小**
——分母小会把 Gordon 终值放大，这时问题在折现率而不在终值本身。

## 五、必须做的交叉验证

这五条是判断模型可不可信的关键，**跑完一定要看**：

### 1. 市场隐含折现率（最重要）

反解出让 DCF 结果等于当前市值的 WACC。物理含义是「市场用什么折现率给这家公司定价」。

- 若与算出的 WACC 相差 **150bp 以上** → 折现率假设与市场共识有分歧
- 典型根因：无风险利率处在历史低位、Beta 偏低、或 ERP 取值偏小
- **处理方式**：把这个分歧写进交付说明，不要装作不存在

> 实例：贵州茅台，算出的 WACC 4.64%（因为 10 年期国债只有 1.8%），
> 但市场隐含折现率 8.31%，相差 367bp。这个差距解释了为什么 DCF 结果是市价的 2 倍。

### 2. 终值占比

| 区间 | 判断 |
|---|---|
| < 45% | 预测期可能太长 |
| 45%–85% | 正常 |
| > 85% | **模型实质上是在押倍数扩张**，不是在做现金流分析 |

### 3. 方法间分歧

DCF 与相对估值相差超过 50% 时，**加权平均的参考价值有限**。
应当先定位是哪一头出了问题，而不是把两个数平均了交出去。

### 4. 隐含资本成本

由当前 PE 反推：`隐含资本成本 ≈ 1 ÷ PE + 可持续增长率`。
与算出的 WACC 差 300bp 以上时，核对 Beta / ERP / 增速哪个偏了。

### 5. 永续增长率

不得超过该市场的上限（见第一节）。超了模型会自动按上限处理并告警。

## 六、方法适用性（什么时候必须停下来说"这个不能用"）

| 公司类型 | 规则 |
|---|---|
| **银行 / 保险** | ❌ **不要用标准 DCF**。债务是经营资金而非融资，WACC 口径不成立。改用 DDM 或剩余收益模型 |
| **REITs** | ❌ 不用 DCF，用 P/FFO 或 P/AFFO |
| **尚无收入** | ❌ 不用 DCF，仅用 EV/Revenue，并标注低置信度 |
| **强周期（能源、半导体、航运）** | ⚠ DCF 要用**中周期**正常化盈利，不要用周期顶点的利润 |
| **历史不足 3 年** | ⚠ 用现有数据，标注置信度低 |
| **净利润为负** | ⚠ 跳过 PE/PEG，用 PS 或 EV/Revenue |

**硬性闸门**：

1. `WACC ≤ 永续增长率` → **直接停止**，终值公式失效
2. 终值占比超出 45%–85% → 告警并在交付中说明
3. WACC 超出行业合理区间 → 注明

## 七、数据规则

### as-of 规则（硬要求）

所有市场数据原则上取**估值基准日或之前可获得**的数据。

确需使用基准日之后发布的数据时，必须：
1. 显式标注「**后见信息**」
2. 请使用者确认

每条数据都要记录**出处**与**取数日期**。

### 口径一致性检查

免费数据源存在**母公司报表 vs 合并报表**混用的问题。

**实测案例**：新浪给五粮液 `000858` 的 2025 年营收只有 2024 年的 45%
（2025Q3 累计 306 亿 vs 2024Q3 的 679 亿），疑为母公司口径。

**模型的自动检查**：营收或净利同比跳变超过 **40%** 即标记异常年份。

| 公司 | 2024 | 2025 | 同比 | 系统判断 |
|---|---|---|---|---|
| 五粮液 | 891.8 亿 | 405.3 亿 | −54.6% | ⚠ 拦截 |
| 洋河股份 | 288.8 亿 | 192.1 亿 | −33.5% | 真实下滑，未误伤 |
| 古井贡酒 | 235.8 亿 | 188.3 亿 | −20.1% | 真实下滑，未误伤 |

处理：从历史期中剔除异常年份，并在驾驶舱与底稿中显著告警。
**遇到这类警告，请核对年报原文再决定是否手工补回。**

### 拿不到就说拿不到

取不到的数据**如实标为「未查询到」**，不要用近似值冒充原值。

已知取不到的：
- **分业务收入构成**（各条线各贡献多少收入）——免费源不提供，需查年报「主营业务分行业、分产品情况」附注
- A 股折旧摊销（D&A）——新浪现金流量表补充资料无此科目

2. `sources` 必须填全，注明出处与取数日期
