# FinScope 估值模块（Comps + DCF + SOTP）

对单一主体做股权估值，**三种方法互相印证**，最后融合成一个结论。

## 交付物

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 本文件——告诉 Agent 怎么做 |
| `INPUT_SCHEMA.md` | 需要什么输入 |
| `OUTPUT_SCHEMA.md` | 输出什么（统一 valuation JSON） |
| `RULES.md` | 金融规则、默认值及其理由、边界条件 |
| `demo/` | 最小可运行案例（A 股 + 美股，输入与输出各一份） |
| `cli.py` / `engine/` | 可执行实现 |
| `README.md` | 怎么跑起来 |

## 工作流程

### 第 1 步 · 判断适用性

先看这家公司**适不适合**用某一种方法，不要默认三法全上：

| 公司类型 | DCF | 相对估值 | SOTP |
|---|---|---|---|
| 成熟、现金流可预测 | ✅ 主力 | ✅ | — |
| 高增长（未盈利） | ⚠ 慎用 | ✅ 主力（PS / EV-Revenue） | — |
| 多分部集团 | ✅ | ✅ | ✅ 主力 |
| 银行 / 保险 | ❌ 用 DDM 或剩余收益 | ✅（PB / P-TBV） | — |
| 周期性（能源、半导体） | ✅ 用中周期正常化 | ✅ | 有时 |
| 尚无收入 | ❌ | 仅 EV-Revenue，标注低置信度 | — |

不适合就**明说**，不要硬套一个 DCF 出来。

### 第 2 步 · 确认假设

所有参数先定下来再取数。默认值见 `RULES.md`，核心几条：

- 预测期 5 年；永续增长率 **A 股上限 4.0%、美股上限 3.0%**（按各自长期名义 GDP）
- 利润率、折旧摊销率、资本开支率、营运资本率一律取**近三年中位数**（不是最近一年）
- 税率取近三年有效税率中位数，夹在 15%–30%
- 同业取 4–6 家，倍数取**中位数**而非均值
- 无风险利率用**基准日的 10 年期国债收益率**，并记录取数日期

### 第 3 步 · 取数

```bash
py valuation/cli.py value 600519 --peers peers.json     # A 股
py valuation/cli.py value AAPL --market US              # 美股
```

数据源优先级：**iFinD 官方接口 > Choice 官方接口 > akshare（A股）/ yfinance（美股）**。
用 `py valuation/cli.py health` 看当前生效的是哪个。

**所有取数必须注明出处与取数日期，并遵守 as-of 规则**（不晚于估值基准日；
确需用基准日之后的数据时，显式标注「后见信息」）。

### 第 4 步 · 三法计算

**DCF**：
```
收入增速：首年（一致预期或历史 CAGR）→ 永续 g，线性衰减
FCFF = EBIT×(1−税率) + 折旧摊销 − 资本开支 − 营运资本增加
WACC = E/V×Ke + D/V×Kd×(1−t)，Ke = rf + β×ERP + 规模溢价
终值 = (Gordon 法 + 退出倍数法) ÷ 2
股权价值 = 企业价值 + 现金 − 有息负债 − 少数股东权益 − 优先股
```

**相对估值**：各选用倍数取同业中位数，分别算出隐含股权价值，再取中位数。
目标与同业在增速/利润率/杠杆上差异明显时，对倍数做 ±10%~30% 调整并说明理由。

**SOTP**：仅在有多分部数据时启用。各分部用纯业务同业倍数估值，加总后扣总部费用与净负债。

### 第 5 步 · 融合与情景

```
无 SOTP：DCF 50% + 相对估值 50%
有 SOTP：DCF 40% + 相对估值 30% + SOTP 30%
```

再给 **5×5 敏感性矩阵**（WACC × 永续增长率）与 **Bull / Base / Bear 三情景**
（收入增速 ±300bp、EBIT 利润率 ±200bp、WACC ∓100bp）。

### 第 6 步 · 交叉验证（必须做，不能跳过）

这几条是判断模型可不可信的关键：

1. **市场隐含折现率**：反解出让 DCF 等于当前市值的 WACC。若与算出的 WACC 差 150bp 以上，
   说明折现率假设与市场共识有分歧，必须写进交付说明。
2. **终值两种算法偏离度**：Gordon 与退出倍数偏离超 30% 要回头核对；偏离的常见根因是
   `WACC − g` 太小，分母把 Gordon 终值放大了。
3. **终值占企业价值比例**：超出 45%–85% 要提示。超过 85% 意味着这个模型实质上是在押倍数扩张。
4. **方法间分歧**：DCF 与相对估值相差超过 50% 时，加权平均的参考价值有限——
   应当先定位是哪一头出了问题，而不是把两个数平均了交出去。
5. **隐含资本成本**：由当前 PE 反推的隐含资本成本与算出的 WACC 差 300bp 以上时，核对 β / ERP / 增速。

模型会自动跑这些检查并把结论放进 `warnings`。

### 第 7 步 · 输出

跑完后产出两份文件：

- `<标的>_valuation.json` —— 统一结果 JSON，**D 的总集成读这个**
- `<标的>_valuation.xlsx` —— Excel 底稿，公式联动，蓝字可改

汇报时按这个顺序讲：**结论先行**（融合每股价值、对市价高估还是低估多少、哪个方法最乐观）
→ 三法结果与权重 → DCF 关键假设 → 同业对比 → 敏感性 → 三情景 → 关键风险。

## 关键规则

- **所有数值计算由 Python 完成**，模型只产出结构化参数，不在自由文本里给数字
- 数据来源必须注明出处与取数日期；非官方源要标出来
- 拿不到的数据**如实说「未查询到」**，不要用近似值冒充原值
- 银行/保险不用标准 DCF；REITs 用 P/FFO；未盈利公司跳过 PE
- 终值永续增长率不得超过该市场的长期名义 GDP 上限
- 交付稿必须声明：本结果仅供研究与教学用途，不构成投资建议

## 已知边界

- SOTP 需要分部财务数据，免费数据源通常取不到，需使用者手工提供
- 可比公司倍数在未接入 iFinD / Choice 时需人工确认
- 折旧摊销（D&A）在新浪源常缺失，会用营业利润近似或留空由模型按收入比例估算
- A 股免费源存在口径不一致问题（如母公司报表 vs 合并报表），模型会自动检测同比跳变超 40% 的年份并告警
